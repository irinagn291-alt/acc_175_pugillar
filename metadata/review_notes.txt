I recorded this on hardware (latest iOS), starting with the app icon on the Home Screen so you can see a clean launch. Pugillar is a two-person diary that lives on a single phone. Couples pass the device. Each writes a half that the other cannot read until both sides have ink and someone seals the day. That is the problem it solves: a shared book that is not a chat and not a notes thread you can peek at. Lifestyle, one device, no cloud.

You asked about accounts and UGC. We never create an account, so login / signup / delete-account are not in the app and are not in the recording. What people type is only for the two of them, on that iPhone or iPad. Nothing is published, nothing is shared out, there are no other users to block, and there is no report flow because there is no public surface.

Walkthrough in the clip (and the path you can repeat with no password):

I go through One shared page. Two people., Write first. Peek later., and Save the day, or it stays open. On Name both people I could have typed two names and a start date; instead I used Use defaults, which sets Alex and Sam for today, then Start today's page.

Home is Today's page: rotating question, this week’s strip, word count, streak. I tap Next to change the question, write on the open note, switch name chips, write the second note, then Save today's page. Together shows days since you started, streak, this month, and 7/30/90/365 marks. Past days has a month calendar, search, favorites, and a full-day view with Share day. Settings: names, daily reminder, Export all days, Contact Pugillar, Re-run onboarding, Reset all data.

Past days is empty on a real device until the first save. That is correct, not a bug.

Reviewer setup: install, open, Use defaults or Start today's page, write both notes, Save today's page, open Together and Past days, then Settings for reminder and export. Re-run onboarding and Reset all data are there if you want a second pass.

Permissions: we do not ask for camera, mic, contacts, location, or tracking. You should not see those dialogs. Info.plist still carries NSCameraUsageDescription as a “does not use the camera” line.

Nothing remote is required for writing or sealing. Leaves and the bond are files on the device. Contact Pugillar opens https://navox-ydonosor.pro/contact-us. Policy is https://navox-ydonosor.pro/privacy-policy. No auth provider, no payments, no ad SDK, no model API.

Country does not change screens or copy. Calendar day boundaries and number formats come from the device.
